# Brave Frontier: Legacy

Brave Frontier: Legacy is a fanmade remake of the original Brave Frontier, rebuilt in Unity as an open-source, moddable project.

## Project Goals

- Recreate Brave Frontier as fast as possible.
- Provide a clean, walkable codebase for modders and developers.
- Support an open-source workflow so anyone can fork and build on top of this project.
- Make assets, scene setups, and game systems easy to inspect and modify.
- Encourage collaboration through branches, pull requests, and shared improvements.
- Provide tools for the creation of Units, Missions, Summons and more.

## What’s Included

- Core Unity scenes and project settings needed to run the game.
- Script systems for units, abilities, UI, and game flow.
- Resource and sprite assets representing characters, skills, and UI.
- Eventually, tools to aid modders and fork projects.

## Why This Project

Brave Frontier: Legacy is meant to be a community-friendly remake rather than an exact copy. It is designed to be a platform for learning and creating, with the following values:

- Modifiability: the project should be straightforward to change and grow.
- Transparency: project files and systems are visible and editable.
- Accessibility: developers of all skill levels should be able to explore the code and assets.
- Community: the repo is intended for forking, remixing, and shared development.

## Get Started

1. Clone the repository.
2. Open the project in Unity.
3. Open the main scenes under `Assets/Scenes`.
4. Explore the `Assets/Scripts` folder to understand game logic.
5. Modify assets, add new units, or extend systems to personalize the experience.

## Contributing

Anyone can contribute to Brave Frontier: Legacy. Suggested contribution paths include:

- Fixing bugs or improving existing systems.
- Improving documentation and developer guides.
- Refactoring code for clarity and maintainability.

Feel free to fork the repository or submit a pull request with your changes.
